# More Projects

More interactive websites by Vadym Rogynskyi.

| Site | What it is |
|---|---|
| [Basis](basis/) | A personal and business finance dashboard: import bank CSVs, auto-categorize, chart trends and get recommendations. |
| [Baseline](baseline/) | A junior-and-pro tennis pathway reference with ITF/Tennis Europe/UTR structure and steps to raise your ranking. |
| [Speakeasy](speakeasy/) | Language roleplay practice by level and scenario, with a vocabulary notebook. (The AI chat works only inside Claude.) |
| [Cadence](cadence/) | A workout logger for any sport with progress charts, load suggestions and training programs. |

Each site is a single self-contained `index.html` file with no build step. Open any of them in a browser, or view them live on GitHub Pages.
